# Прототип роекта парсера резюме, разработанный в рамках хакатона ML TalentMatch

Задача в рамках хакатона ML TalentMatch: Разработать и реализовать алгоритм, который будет сопоставлять резюме кандидата с описанием вакансии и определять, насколько данный кандидат соответствует условиям вакансии.

Запуск проекта:

```
sudo docker build --no-cache -t resume_parser .
sudo docker run -d --name resume_parser -p 80:80 resume_parser

```

Далее можно воспользоваться Swagger для тестирования по адресу:
http://127.0.0.1/docs
